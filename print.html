One-time setup on this tablet

  1. Install RawBT and Server for RawBT from the Play Store. In RawBT, pick the Bluetooth receipt printer and print its test page.
  2. Open Server for RawBT once so it runs in the background, and let it ignore battery optimisation.
  3. Open this page from the bookmark, tap Start printing, allow access to devices on the local network if Chrome asks, then tap Test print.

The tablet screen should stay on with this page open (it asks Chrome to keep the screen awake). Orders paid while it was closed print when you open it again.
